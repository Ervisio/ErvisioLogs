## Packages

| File | Use |
|---|---|
| `ervisio-logs-0.1.3-linux-amd64.tar.gz`, `-linux-arm64.tar.gz` | Standalone: binary with the web UI, systemd unit, `install.sh` |
| `ervisio-logs-0.1.3-docker.tar.gz` | Docker Compose bundle, from `ghcr.io/ervisio/ervisio-logs:0.1.3` |
| `ervisio-logs-0.1.3.tar.gz` (+ `.sha256`) | Ervisio plugin, unsigned, in the registry format. Install the signed copy from Plugins › Browse once it is listed |
| `ervisio-logs-0.1.3-ervisio-plugin.tar.gz` | The same plugin under its first name |
| `SHA256SUMS` | Checksums of the packages |

## Changes

- **Workspaces**: the projects page, now "Workspaces and projects", lists your workspaces. Pick one to see and add
  its projects, or press **New workspace** to make another; you become its owner. ADR 0016.

## Upgrading from 0.1.2

Upgrade the plugin in Ervisio and press **Update**, or install the new standalone or Docker package. No database
migration.

## Known limits

Same as 0.1.2. Renaming or deleting a workspace still needs the API.
