Documentation is now available inside the app, in English and Italian.

## Changes

- **Documentation** in the main navigation and command palette, available to all signed-in users, including users
  without a workspace or project. Articles have stable `/docs/<topic>` addresses.
- Nine searchable guides: getting started, JSON ingest API, search and live logs, tokens and permissions, storage
  and retention (S3, SFTP / Storage Box and local folders), FiveM, alerts and webhooks, deployment and troubleshooting.
- Copyable curl, server.cfg and server-side Lua examples. Clipboard failures explain how to copy manually.
- The Ervisio plugin is version **0.1.5**, deploying the matching application release with the new documentation.
  Capabilities and permissions are unchanged.
- Release maintainers can run the existing release workflow manually from `main` with a stable version. It checks
  plugin versions and release notes first, builds the artifacts, then tags the exact checkout and creates the usual
  draft release. Tag-triggered releases remain supported.

## Upgrade

Update the plugin in Ervisio, then press **Update** in the Ervisio Logs plugin page to update the running app.
For manual installs, use the 0.1.5 standalone or Docker bundle. No database migration or configuration change.

The new guides describe existing behaviour; FiveM examples and the experimental OTLP receiver retain their existing
validation limitations. No in-game tests were performed for this release.
