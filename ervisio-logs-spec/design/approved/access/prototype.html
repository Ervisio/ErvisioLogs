Il server scrive il codice di setup nei suoi log all'avvio. Cerca questa riga e copia il valore di setup_code:

{"level":"WARN","msg":"first run: no users exist. Use this one-time setup code to create the instance admin account","setup_code":"…"}

Con Docker Compose: docker compose logs app | grep setup_code

Il codice vale una volta. Ogni riavvio ne genera uno nuovo finché non crei l'account. Se hai impostato ERVISIO_LOGS_SETUP_CODE, usa quel valore: nei log non compare.
